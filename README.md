# Integración de Datos

Repositorio que reúne diferentes prácticas y proyectos desarrollados en el ámbito de la **Integración de Datos**, abordando distintas técnicas relacionadas con el almacenamiento, transformación y acceso a la información.

El contenido está organizado en varios bloques que permiten trabajar con bases de datos, procesos ETL y herramientas de mapeo objeto-relacional.

## Contenido del repositorio

```text
ID/
├── BDD/
├── ETL/

```

### BDD

Ejercicios y prácticas relacionados con **bases de datos**, centrados en el almacenamiento, gestión y consulta de información.

### ETL

Trabajo relacionado con procesos **ETL (Extract, Transform, Load)**, utilizados para:

- Extraer información desde diferentes fuentes.
- Transformar y adaptar los datos.
- Cargar los resultados en el sistema de destino.

Este tipo de procesos constituye una parte fundamental de los sistemas de integración y procesamiento de datos.

### ORM

Prácticas relacionadas con el uso de **ORM (Object-Relational Mapping)** para facilitar la comunicación entre aplicaciones y bases de datos relacionales.

El objetivo es trabajar con los datos mediante objetos y modelos de aplicación, reduciendo la dependencia de consultas SQL escritas directamente en el código.

## Objetivos

El repositorio recoge distintos trabajos orientados a poner en práctica conceptos como:

- Diseño y gestión de bases de datos.
- Integración de información procedente de distintas fuentes.
- Procesos de extracción, transformación y carga de datos.
- Persistencia de información.
- Mapeo objeto-relacional.
- Acceso y tratamiento de datos desde aplicaciones.
